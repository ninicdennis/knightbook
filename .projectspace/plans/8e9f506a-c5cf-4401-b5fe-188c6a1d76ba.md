Launch the public Knightbook website: a small static site with a homepage, a download page, release history, a privacy page and a focused set of user guides. The website plan and launch criteria are in [the landing page proposal](docs/proposals/landing-page-and-user-documentation.md).

## Decisions made while ticketing (2026-09-29)
- **Site tooling: Astro.** Static output, Markdown guides, no JavaScript by default, which fits the requirement that downloads and instructions work without JS. Recorded formally by the scaffold ticket.
- **Launch platforms: all three.** Windows x64 (NSIS), macOS Apple silicon and Intel (DMG), Linux x64 (deb). AppImage stays out until 68f54f52 (D-028). The Linux and macOS validation tickets are therefore launch prerequisites.
- **Existing tickets:** "Build and publish a GitHub Release" is attached here as well as to Ship MVP; the Linux and macOS validation tickets stay in Ship MVP and are dependencies of the website's install guide and launch check.

## Still open (owned by tickets in phase 1)
