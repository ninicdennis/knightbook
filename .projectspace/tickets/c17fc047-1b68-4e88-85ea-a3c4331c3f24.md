# Edit plans in the app

## Intended outcome
From the Plans pane the user can create a plan, add, rename and reorder its phases, and attach or detach tickets, without asking an AI or opening the file.

## Acceptance criteria
- Create a plan from a title; add a phase; rename, reorder and remove phases, keeping each phase's id so its tickets stay attached.
- Attach an existing ticket to a phase by choosing it from the board's tickets, and detach it. Neither changes the ticket's status, dependencies or backlog order.
- Every write goes through a new host operation that carries the plan revision the window read. A stale write is refused and the pane reloads and says so, as the board does for moves.
- Validation stays in `packages/core` (`createPlan`, `updatePlan`); the host calls it rather than re-implementing it.
- Keyboard reachable, with accessible names, in both colour schemes and at a narrow width.
