# Uninitialized folder guidance and one-click setup

## Intended outcome
Opening a folder with no project records explains what will happen and lets the user set it up in the app, without an AI tool and without spending any AI credit.

## Acceptance criteria
- The screen says what a Projectspace project is, and that setup adds only a .projectspace folder and changes no existing file.
- A Set up this folder button initializes it through the same core operation MCP uses, and the project opens straight away.
- If a README.md or a docs folder exists, offer to include them in place. The user confirms; nothing is included silently.
- Never write into an existing .projectspace that holds unrelated files. Say why and change nothing.
- Explains how to connect an AI client afterwards, with the copy-configuration action beside it.
- Failures are specific: permission denied, read-only folder, and so on.

## Notes
Today the screen tells the user to use an AI tool, which costs credit just to get an empty project. The AI-driven onboarding for an existing application stays available but becomes optional.
