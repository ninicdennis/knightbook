# Filter each board column by ticket type and state

## Intended outcome
Each column can be narrowed to the tickets the user cares about right now, by type and by state, without affecting the other columns.

## Acceptance criteria
- Every column has its own filter control for type: Feature, Bug, Task and untyped, multi-select.
- The same control filters by state: blocked, waiting on dependencies, ready to start, flagged by a failed prerequisite, and review status (unreviewed, reviewed, changed since review).
- A filtered column shows that it is filtered and how many tickets are hidden, with one action to clear it, so hidden tickets never look missing.
- A column whose filter matches nothing says so, distinct from an empty column.
- Filters are view state only; they never change ticket files or backlog order, and dragging within a filtered Backlog keeps the full order correct.
- Filters are keyboard accessible and work at narrow and wide window widths.

## Notes
Requested by the user on 2026-09-23. Assumption to confirm when this starts: 'states' means the ticket conditions above, since status is already the column itself. Whether filters persist between launches is open; the default proposal is to remember them per project locally, never in project files.
