## Intended outcome
Each Restore button in the Archive view says which ticket it restores, so screen-reader users can tell the rows apart.

## Acceptance criteria
- Each Restore button's accessible name includes the ticket title, for example "Restore Regression probe ticket", while the visible label can stay "Restore".
- A test with two archived tickets restores the second by its button's name.

## Notes
Found in the 2026-11-10 regression pass of the packaged arm64 app on the Mac mini (macOS, AeroSpace), driven through a scratch copy of this project.

With 64 archived tickets the view had 64 buttons each named just "Restore".
