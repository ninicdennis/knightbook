# Page titles, canonical URLs, sitemap, social image, and redirects

## Intended outcome
Every public page can be found and shared cleanly, and moved guides keep working.

## Acceptance criteria
- Every page has a unique title and description; the build fails if two pages share one or a page has none.
- Canonical URLs use the production domain from the host and domain decision.
- A sitemap lists public pages only, excluding drafts, previews and the 404 page.
- A social-preview image built from the approved logo is used by every page.
- Redirects are declared in one place in the repository and built into the site as static pages with a meta refresh and a canonical link, since GitHub Pages has no server redirects (D-044); a test checks that each redirect target exists.
- `robots.txt` allows production. Previews are not hosted (D-044) and are `noindex` already (23bed0a1).

## Notes
Spec §9 "discovery and sharing".

## Handoff (2026-10-21)

### What changed
- Canonical link and Open Graph tags (title, description, url, image, site name) on every page, on `https://knightbook.xyz` (D-046); none on the 404 page.
- Social image: the approved mark from `logo.ts` at 512×512 PNG, `twitter:card` summary.
- `sitemap.xml` (site pages plus published, non-draft guides) and `robots.txt` (allow plus sitemap in production; disallow all in a preview).
- Redirects declared once in `src/layout/redirects.ts`, starting with `/downloads/` to `/download/`, built by Astro as meta-refresh pages with a canonical link.
- `metadataCheck()` integration: the build fails, naming each page, on a missing or repeated title or description.

### How it was checked
Website suite with Chromium: 169 passed. New `discovery.test.ts` (8 tests): canonical and og:url per page against its path; sitemap equal to the built pages minus 404, redirects and draft guides, with the preview build's draft guides as the data that proves drafts are left out; social image is the logo at 512×512 read from the PNG header; each redirect page's refresh and canonical, and that its target page exists; preview robots.txt; no repeated titles or descriptions across the real site; the check's message for a missing description and a shared title; and a real build with two fixture guides sharing a title fails and names them. Typecheck, Oxlint and Prettier clean. The verifier was not run.

### Not verified
- The production `robots.txt` (allow plus sitemap): no production build can succeed while drafts remain; by reading only.
- How link previews look in real services (Slack, X, iMessage).
