# Page titles, canonical URLs, sitemap, social image, and redirects

## Intended outcome
Every public page can be found and shared cleanly, and moved guides keep working.

## Acceptance criteria
- Every page has a unique title and description; the build fails if two pages share one or a page has none.
- Canonical URLs use the production domain from the host and domain decision.
- A sitemap lists public pages only, excluding drafts, previews and the 404 page.
- A social-preview image built from the approved logo is used by every page.
- Redirects are declared in one place in the repository and built into the site as static pages with a meta refresh and a canonical link, since GitHub Pages has no server redirects (D-044); a test checks that each redirect target exists.
- `robots.txt` allows production. Previews are not hosted (D-044) and are `noindex` already (23bed0a1).
