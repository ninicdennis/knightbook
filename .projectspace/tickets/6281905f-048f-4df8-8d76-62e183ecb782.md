# Write the installation, updating, and removal guide

## Intended outcome
`/docs/installation/` tells users on each launch platform exactly what the installer does, how to update by hand, and what uninstalling keeps, based on recorded validation rather than assumptions.

## Acceptance criteria
- One section each for Windows x64 (NSIS), macOS Apple silicon and Intel (DMG), and Linux x64 (deb), each covering choosing the right download, installing, where it installs, first launch, and supported OS versions from D-028.
- The publisher, signing or notarization warning users will see on each platform is described as it was recorded in validation. There are no generic instructions to turn off OS protections; unexpected warnings go to support.
- Updating: find the installed version, back up project data, install the new package, reconnect the AI client if runtime paths changed, confirm the project opens. It states plainly that there is no in-app updater yet.
- Uninstalling: what is removed and what stays, with app preferences and project files described separately, as observed in validation.
- Every statement comes from the Windows, Linux and macOS validation results; anything not validated is left out or marked as unverified.

## Notes
All three platforms are launch targets (user, 2026-09-29). AppImage is not offered (D-028, ticket 68f54f52). Spec §7 "Installation, updating, and removal".
