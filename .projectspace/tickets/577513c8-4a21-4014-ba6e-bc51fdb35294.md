# Choose the website host and domain

## Intended outcome
The static site has a chosen host and an owned domain, with the reasoning recorded, so deployment, canonical URLs and the privacy page can be written against real facts.

## Acceptance criteria
- At least two hosts suited to static Astro output are compared on: HTTPS, custom domain, deployment previews, redirect support, rollback to a previous build, cost, and what visitor data the host logs by default.
- A host is chosen, and the comparison and choice are recorded as a numbered, dated decision.
- A domain is chosen, and its availability and a basic trademark check for "Knightbook" are recorded. Purchasing and DNS setup are done by the user.
- What the chosen host logs about visitors (IP addresses, retention) is written down for the privacy page.

## Notes
Site tooling is already decided: Astro, chosen by the user on 2026-09-29. Spec §9 lists the required host capabilities and asks that binaries stay at the release origin, not in site source control. Spec §11: domain and hosting are needed before production deployment, not before the private preview.

## Comparison (2026-10-21, drafted by an AI tool; the choice is the owner's)

Both hosts are free for this site now that the repository will be public (D-043).

| | Cloudflare Pages | GitHub Pages |
| --- | --- | --- |
| HTTPS and custom domain | Yes, certificate managed; up to 100 custom domains per project | Yes, certificate from Let's Encrypt; one custom domain |
| Deployment previews | Every pull request gets its own preview URL; no cap on active deployments | None built in |
| Redirects | `_redirects` file: 2,000 static and 100 dynamic | None at the server; only HTML meta-refresh pages |
| Rollback | Any earlier deployment can be made live again from the dashboard | Re-run an earlier deployment workflow, or revert and redeploy |
| Cost and limits | Free: 500 builds a month, 20,000 files, 25 MiB a file | Free on public repositories |
| Visitor data | Processes visitors' IP addresses and traffic data; the privacy policy (effective 2025-11-04) gives no fixed retention period. No analytics unless Web Analytics is turned on | Logs every visitor's IP address "for security purposes", signed in or not |

Sources: Cloudflare Pages limits (developers.cloudflare.com/pages/platform/limits), Cloudflare privacy policy (cloudflare.com/privacypolicy), "What is GitHub Pages?" (docs.github.com). Checked 2026-10-21.

**Recommendation: Cloudflare Pages.** Deployment previews and one-click rollback are what ticket 23bed0a1 asks for, and real redirects are what 0f142dd8 needs; GitHub Pages has neither. Release downloads stay on GitHub Releases either way, so the 25 MiB file limit does not matter.

**Domain:** not checked. Domain-registry lookups are blocked from the environment this was drafted in, so availability of knightbook.app, .dev or .com and the trademark check are still to do.
