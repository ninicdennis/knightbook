# Shared core library

## Intended outcome
One library loaded by both the desktop host and the MCP server, so the two cannot validate records differently (design section 1).

## Acceptance criteria
- Every write re-reads under a cross-process lock, compares exact bytes with the caller's revision, and replaces through a temp file.
- A stale write returns a conflict and the current revision instead of overwriting.
- Done is reachable only through the dedicated completion operation, valid only from Verification.
- A prerequisite in Verification or Done satisfies a dependency (D-014).
- Traversal and symlinks that escape the project root are rejected.

## Verification
Checked by the AI, not accepted by the user. 45 tests in packages/core pass, covering the write path, the workflow rules, documents and search, and review.
Known limit: external editors and Git do not honor the lock, so the revision check is the real protection. Races with an uncooperative writer are documented, not eliminated.
