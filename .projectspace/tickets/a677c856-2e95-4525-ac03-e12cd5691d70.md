# Choose the license for the free, source-available release

## Intended outcome
The owner's terms for distributing Knightbook are decided and written down, so the website, footer, FAQ, README and download page can state them instead of guessing.

## Acceptance criteria
- A license is chosen and its text is committed as `LICENSE` at the repository root.
- Pricing is stated explicitly. Settled 2026-10-21: Knightbook is free.
- The public download origin is chosen. Settled 2026-10-21: the repository becomes public, so GitHub Release assets are the public download (made real by b2919bbe).
- Each choice is recorded as a numbered, dated decision in the specification with its reasoning.

## Notes
Spec §2 and §11: infer neither license nor pricing from repository visibility, and never let a visitor discover after clicking that a download needs authentication. This ticket is the owner's decision; an AI can draft options but not decide.

2026-10-21: the owner changed direction to "free, source code available", with the repository public at launch. "Source-available" can mean an OSI open-source license (MIT, Apache-2.0) or a license that shows the source but limits use (FSL, BSL, PolyForm); that choice is still open. Blocks the website's license copy (8c7b21b1), the README and contributing files (409f0312) and making the repository public (b2919bbe).
