# Choose the license, pricing, and public download origin

## Intended outcome
The owner's terms for distributing Knightbook are decided and written down, so the website, footer, FAQ and download page can state them instead of guessing.

## Acceptance criteria
- A license is chosen and, if it is an open-source or source-available license, a `LICENSE` file exists at the repository root.
- Pricing is stated explicitly (for example free, or paid with terms), even if the answer is "free for now".
- The public download origin is chosen: either the `ninicdennis/knightbook` repository becomes public so GitHub Release assets download without a login, or another public location is named.
- Each choice is recorded as a numbered, dated decision in the specification with its reasoning.

## Notes
Spec §2 and §11: infer neither license nor pricing from repository visibility, and never let a visitor discover after clicking that a download needs authentication. This ticket is the owner's decision; an AI can draft options but not decide. Blocks the homepage FAQ, footer, and download page copy.
