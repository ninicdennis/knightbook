# Decide supported OS versions, architectures, and Linux package formats

## Intended outcome
Open decision 6 in the specification is settled and recorded, so platform validation and release work have a defined target.

## Acceptance criteria
- A short write-up lists the options for minimum Windows and macOS versions, x64 and arm64 per platform, and Linux formats (for example AppImage, deb, rpm), with what each costs to build and test.
