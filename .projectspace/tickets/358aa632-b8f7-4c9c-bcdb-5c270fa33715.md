# Accessibility and no-JavaScript pass across the website

## Intended outcome
Every page template meets the spec §8 accessibility checks, and downloads and instructions work with JavaScript off, with automated tests that keep it that way.

## Acceptance criteria
- Playwright smoke tests cover the home, download, docs index, one guide, releases, privacy and 404 pages at a narrow (375px) and a wide (1440px) viewport, and fail on horizontal page scroll.
- An automated accessibility scan (for example axe) runs in those tests with no serious or critical violations.
- A test with JavaScript turned off reaches every download link and the full text of a guide.
- Checked by hand and recorded on this ticket: keyboard-only navigation, visible focus, skip link, heading order, meaningful link names, alt text, reduced motion, contrast in light and dark, 200% zoom, and long platform names and filenames.
- The tests run in CI as part of the website checks.
