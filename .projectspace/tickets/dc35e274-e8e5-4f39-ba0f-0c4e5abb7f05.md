# Validate on macOS (Apple silicon and Intel)

## Intended outcome
The core workflow is confirmed on macOS 13 Ventura or later for both builds D-028 ships: arm64 (Apple silicon) and x64 (Intel).

## Acceptance criteria
- For each architecture, the matching DMG installs and the app starts. Record the Mac model, chip and macOS version.
- For each architecture, an MCP client connects with the app closed and no system Node on the PATH, and can list and update tickets. This is the check that the Intel build carries an x64 Node, not the arm64 one.
- Edits made outside the app (editor, Git) appear correctly after focus or Refresh.
- A project created on Windows opens on macOS without broken links, and the reverse.
- What it took to open the unsigned app past Gatekeeper is written down, since signing and notarization are still undecided (D-028).
- Results recorded in the packaging findings, per architecture. If the Intel build could only be run under Rosetta on Apple silicon rather than on an Intel Mac, say so; that is weaker evidence.
