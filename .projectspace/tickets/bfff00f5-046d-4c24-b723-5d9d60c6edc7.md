# Edit a ticket's dependencies and related documents

## Intended outcome
From the ticket detail view the user can add and remove prerequisites and linked documents, which today only MCP can change.

## Acceptance criteria
- Prerequisites are chosen by ticket title from a searchable list; the ticket itself and archived tickets are not offered.
- A change that would create a cycle, or refer to an unknown ticket, is refused with a plain explanation, using the same validation as MCP's ticket_update.
- Related documents are chosen from the workspace's included documents.
- Dependency readiness and waiting notes on the card and in the detail view update immediately after saving.
- The write carries the ticket's revision and handles a conflict the same way other ticket edits do.

## Notes
D-012 and D-014 define dependencies and readiness. Explicit dependency overrides remain an open decision and are not part of this ticket.

- App: contract operation `setTicketLinks`, handled as `ticket:setLinks` (`main/tickets/ticket-edit-ipc.ts`): validates both lists, drops repeats, writes nothing when both lists are unchanged, otherwise calls `updateTicket`.

Refusals show in the dialog with the choice kept; a conflict reloads the board, says nothing was overwritten, and offers "Load the current version". Only one editor (links or source) is open at a time.
