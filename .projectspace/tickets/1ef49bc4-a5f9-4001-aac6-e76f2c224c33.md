# Serve release downloads from a public Cloudflare R2 bucket

## Intended outcome
Visitors can download Knightbook installers without a GitHub login while the repository stays private. Each release's installers and checksums are copied to a public R2 bucket, and a small manifest there names the newest release so the website's download page can link to it.

## Acceptance criteria
- The user has created a Cloudflare account and an R2 bucket with public read access, either on a custom subdomain (for example `downloads.<domain>`) or the bucket's public `r2.dev` address, and written down which.
- An R2 API token scoped to that one bucket, with write access only, is stored as GitHub Actions secrets, and only the release publishing job can read them. Pull-request runs and forks cannot.
- After a release is published on GitHub, the workflow uploads every installer and its checksum to a versioned path (for example `releases/<version>/`) and then updates a `latest.json` manifest (version, date, prerelease flag, file names, sizes, SHA-256). The manifest is written last, so it never points to files that are not there yet.
- Re-running a release does not overwrite files already uploaded for that version.
- A download made from the public URL matches the checksum published with the GitHub Release.
- The origin, its URL and the decision to keep the repository private are recorded as a numbered, dated decision in the specification, which settles the "public download origin" part of a677c856.

## Notes
Created 2026-10-01. The user wants the repository private for now, and GitHub Release assets in a private repository need a signed-in account with access, so they cannot be the public download. Static hosts are not suitable either, because Electron installers (100 MB or more) exceed per-file limits such as Cloudflare Pages' 25 MiB. Uploading uses the S3-compatible API through the AWS CLI already on GitHub's runners, so no new SDK is needed. The account, bucket and token are for the user to create; the workflow step follows once the secrets exist.
