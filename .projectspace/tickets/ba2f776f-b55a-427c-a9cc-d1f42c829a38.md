# Companion workflow guidance

## Intended outcome
Any AI client can learn the intended workflow: read context, separate facts from assumptions, start work only when asked, leave results in Verification, record Done only on the user's explicit instruction, keep handoff notes.

## Acceptance criteria
- Portable Markdown that reads fine without any client (design section 9).
- A packaged skill for clients that support one, validated in a real session.
- Kept apart from project evidence, and says plainly that MCP alone does not enforce the behavior.

## Notes
Today the guidance lives only in tool descriptions.
