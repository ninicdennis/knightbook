# macOS and Linux validation

## Intended outcome
Confirm the core workflow on each platform. Both are first-version requirements (D-007).

## Acceptance criteria
- Install, run, and connect an MCP client with the app closed and no system Node.
- External edits appear correctly; the same project opens on another platform without broken links.
- Linux AppImage: a persistent helper location or a documented supported layout, since the mount path is transient.
- Results recorded.

## Notes
Only Windows has been built and run. The user validates on their own hardware.
