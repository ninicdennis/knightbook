# Make the repository public and check release downloads without signing in

## Intended outcome
`ninicdennis/knightbook` is public, its GitHub Release assets download for anyone, and the repository settings suit a public project.

## Acceptance criteria
- The owner switches the repository to public. An AI tool does not.
- A release installer and `SHA256SUMS.txt` download from a signed-out browser, and the checksum matches.
- Private vulnerability reporting, secret scanning and push protection are on.
- `main` is protected: changes arrive by pull request with the `check` job and the `Pull request title` check required.
- Actions requires approval before running workflows from first-time outside contributors.
- The repository's description, website URL and topics are set.
- The decision to make the repository public, and GitHub Releases as the public download origin, is recorded in the specification, replacing D-040's note that the repository stays private.
