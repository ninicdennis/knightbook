# Create a document from the app, optionally from a starter template

## Intended outcome
The user can create a new Markdown document in a chosen location inside the project, blank or from a small set of optional templates, and it appears in the workspace immediately.

## Acceptance criteria
- The user chooses the file name and folder; the location must be inside the project folder.
- Creating never overwrites an existing file; a name clash is reported and nothing is written.
- A small template set is offered: project definition, specification, decision record. Templates are editable starting points and impose no structure (D-010).
- The new file is included in the workspace and opens in the viewer.
- The core create function is shared with the MCP document-creation ticket (fa05d99e) rather than duplicated.

## Notes
The spec's document organization section asks for creating blank documents or starting from a template. The exact template set was open; the three above are the proposal to confirm when this starts.
