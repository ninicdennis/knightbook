# Validate a clean Windows x64 install of the release build

## Intended outcome
The Windows installer that the website will offer is confirmed to install, launch and serve MCP on a clean machine, which is the evidence the download page and install guide need.

## Acceptance criteria
- The NSIS installer downloaded from the public release URL (not a local build or CI artifact) installs on a Windows 10 or 11 x64 machine or VM with no Node, pnpm or repository checkout present.
- The app launches, and "Choose a project folder" and "Set up this folder" work on a fresh folder.
- An MCP client connects using the configuration copied from the installed app, with the app window closed and no system Node on the PATH, and can list and update tickets.
- The SmartScreen or publisher warning shown at install is recorded exactly, with the signing state of the asset.
- Where the installer puts the app, what uninstall removes, and that project folders survive uninstall are recorded.
- Results are recorded in the packaging findings: Windows version, asset filename and checksum, what passed and what did not.

## Notes
Spec §10: CI packaging by itself is not install evidence. Mirrors the Linux (b2a51f35) and macOS (dc35e274) validation tickets. The user validates on their own machine or VM.
