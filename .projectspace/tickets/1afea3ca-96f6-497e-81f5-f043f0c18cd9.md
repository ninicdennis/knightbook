# Run CI on all three platforms for pull requests once the repository is public

## Intended outcome
Windows and macOS breaks are caught on the pull request instead of at merge, now that the cost reason behind D-031 no longer applies.

## Acceptance criteria
- After the repository is public, GitHub's current pricing page is checked to confirm standard hosted runners are free for public repositories, and the date and finding are recorded.
- If they are, pull requests run `check` and `package` on Windows, macOS and Linux, and D-031 is superseded by a new numbered decision with the reasoning.
- `AGENTS.md`'s CI paragraph matches the workflow.

## Notes
Created 2026-10-21. Post-launch and optional. D-031 limited pull requests to Linux because private-repository minutes ran out. Depends in practice on the repository being public.
