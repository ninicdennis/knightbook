# Write the getting-started guide

## Intended outcome
`/docs/getting-started/` walks a new user from install to a first verified handoff, and it was written by following it on a clean install of the offered build.

## Acceptance criteria
- Covers the eight steps in spec §6: install and open; choose or set up a project folder; find documents; understand the board; optionally connect an AI tool; confirm the connection with the suggested read-only prompt; try a small handoff; return later.
- Each step states the expected result and links to the troubleshooting section for the likely failure.
- A "Use without connecting AI" path covers what the desktop app can do alone, and clearly labels anything that needs an external tool.
- UI labels in the text match the release build exactly (for example "Choose a project folder", "Set up this folder").
- No step needs Git, pnpm, Node or a source build.
- It records the app version it was written against and the date, and was followed start to finish on a clean install; who followed it and on what OS is recorded on this ticket.
