# Formatted editor

## Intended outcome
Edit rendered Markdown in the app while saving ordinary Markdown (T-001).

## Acceptance criteria
- No-op open is byte-identical; unrelated content is preserved on an edit.
- Unsupported constructs are detected before editable rendering, with a read-only fallback. Inline HTML counts until the upstream fix ships.
- Typing behavior (Milkdown issue 2446) is tested in a real editor surface.
- Decide how to handle the table delimiter row that Milkdown narrows.
