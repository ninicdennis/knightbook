# Bring four oversized files under the limit

## Intended outcome
`apps/desktop/src/main/ipc.ts`, `packages/core/src/tickets.ts`, `apps/desktop/src/shared/contract.ts` and `apps/desktop/preview/stub-api.ts` are each back under the project's 400-line hard limit, by moving one cohesive responsibility out of each.

## Acceptance criteria
- Each of the four files is under 400 lines, and no file extracted from them exceeds 300.
- Each extraction is one responsibility that reads on its own, not an arbitrary cut.
- This is a rearrangement: no behaviour, IPC channel, exported name, wording or test changes. Existing import sites keep working, re-exporting where that avoids churn.
- Every existing test passes unchanged; typecheck, lint and formatting are clean.
