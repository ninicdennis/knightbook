# Organize desktop main and core source into feature folders

## Intended outcome
`apps/desktop/src/main` (47 flat files) and `packages/core/src` (55 flat files) follow the same file-organization rule as the renderer.

## Acceptance criteria
- `main/` is grouped by feature (for example window, tickets, documents, mcp, setup, project), with entry files at the root.
- `packages/core/src` is grouped by feature (for example records, tickets, documents, review, search), and `index.ts` stays the package's only public entry, so nothing outside core changes.
- Moves are done with `git mv`; no behaviour changes; `pnpm check` and `pnpm build:mcp` pass.

## Notes
Follows the renderer reorganisation and the rule it records. `packages/mcp/src` and `apps/desktop/src/shared` are under the split threshold and stay as they are.

## Handoff
**What changed:** On branch `feature/file-organization`, uncommitted. 98 files were moved with `git mv`.
- `main/` became `window/` (10), `project/` (11: project view, app state, remembered projects, state migration, folder setup, setup and settings handlers), `tickets/` (10, including the archive handler), `documents/` (6, including the plan and review-changes handlers, since each would have been a folder of fewer than three), and `mcp/` (7, including skill install). `index.ts`, `ipc.ts` and `guard.ts` stay at the root.
- Core became `records/`, `tickets/`, `documents/`, `plans/`, `review/`, `search/`, `mcp/` and `test/` (`fixture-project.ts`). `index.ts` is still the only public entry, so nothing outside core changed.

Relative imports were rewritten by script, and Prettier re-wrapped two files. Other edits:
- File paths in a comment in `renderer/theme/surfaces.css` and in two docs (`validation-scenario-results.md`, `research/plans-review-documents-research.md`).
- The AGENTS.md rule now says "feature folder" and that `test/` is exempt from the three-file minimum.
- D-027 in the spec now records the main and core layouts.

**How it was checked:** `pnpm check` passes, with the same test-file counts as before (desktop 53, core 23, mcp 8, packaging 7, editor-preservation 2). `pnpm build:mcp` and `electron-vite build` succeed.
