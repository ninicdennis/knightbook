# Organize renderer source into feature folders

## Intended outcome
`apps/desktop/src/renderer` is grouped by feature instead of one flat folder plus `components/` and `hooks/`, and the rule for where files go is written down so the tree stays tidy.

## Acceptance criteria
- A file-organization rule is recorded in AGENTS.md (Conventions) and as a numbered decision in the technical design.
- Renderer files live in feature folders (app, board, tickets, documents, markdown, plans, review, search, mcp, test); `components/` and `hooks/` are gone.
- Tests sit beside the feature they cover; shared test support is in `test/`.
- Moves are done with `git mv`; no behaviour changes.
- `pnpm check` passes and the packaged app launches and shows the board.

## Notes
Agreed with the user on 2026-09-25. Step 2 (main and core) is a separate ticket.
