# Create a ticket from the board

## Intended outcome
The user can add a ticket from the Backlog column without an AI tool or an external editor.

## Acceptance criteria
- A New ticket action on the Backlog column opens a form with a required title, an optional type (Feature, Bug, Task or none) and an optional body.
- The body starts from the board's usual shape: Intended outcome, Acceptance criteria, Notes.
- The new ticket is written through the same core create function and write lock MCP's ticket_create uses, lands at the end of the backlog order, and opens in the detail view.
- An empty title cannot be submitted, and a failed write is shown with its reason instead of silently closing the form.
- Keyboard only: the action and form are reachable and submittable without a mouse.

## Notes
Found while surveying the app on 2026-09-23: the host has no ticket-creation IPC operation, so tickets can only be created through MCP or by hand. Pairs with the source-editing ticket for changing a ticket after it exists.
