# Reordering and removal

## Intended outcome
Manual backlog order and removing a document from the workspace are reachable by a user or an AI.

## Acceptance criteria
- An MCP operation and a board interaction that edit only backlog_order in the manifest.
- A documents_remove tool exposing the existing core removal.
- Duplicate or unknown order entries are reported, never deleted.

## Notes
The core library already has both operations. Neither has a tool or a UI. Until then, backlog order is creation order.
