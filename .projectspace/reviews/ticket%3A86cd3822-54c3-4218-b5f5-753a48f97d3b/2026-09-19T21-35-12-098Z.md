# Bundled MCP runtime

## Intended outcome
An AI client starts the shipped runtime directly, with no system Node and no running GUI.

## Acceptance criteria
- Runtime and server sit outside the ASAR archive at a stable installed path.
- The saved client command keeps working after resources are replaced.

## Verification
Checked by the AI, not accepted by the user. Passes against a real electron-builder --dir build on Windows.
Not verified: macOS, Linux, an installer, code signing. The runtime is 90 MB of a 458 MB app. See the packaging findings.
